== Building

=== First Set up the environment 

To enter the shell containing java25 and gradle (First install nix, see below)
```
nix --extra-experimental-features 'nix-command flakes' develop
```

To launch your tests:
```
./gradlew clean test
```

To package your application:
```
./gradlew clean assemble
```

To run your application (Default Port 8080):
```
./gradlew clean run
```

=== Change Port

in flake.nix file, change VERTX_APPLICATION_PORT to port number of your liking
